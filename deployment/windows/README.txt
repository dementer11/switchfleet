SwitchFleet v0.4.0 для Windows

Запуск: дважды щёлкните Start-SwitchFleet.cmd. Приложение откроется в браузере по адресу http://127.0.0.1:18787. Повторный запуск открывает уже работающую копию.

Остановка: дважды щёлкните Stop-SwitchFleet.cmd; VM завершится штатно.

Первый запуск создаёт data.qcow2 для данных приложения. Этот диск сохраняется между запусками; switchfleet-v1.qcow2 остаётся неизменяемой базой. Приложение стартует без доступа к Интернету. VM использует 3 ГБ ОЗУ.

Для резервной копии сначала остановите SwitchFleet, затем скопируйте всю папку приложения целиком. В ней находятся программа, базовый диск и пользовательский диск данных.
